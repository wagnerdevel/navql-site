Privacy Policy

Last updated: November 13, 2026

NavQL is a database client that runs on your computer. Your connections, passwords, queries and data stay there. This page lists everything the app and this website send over the internet.

Your databases and connections

Saved connections, passwords, SSH keys, saved queries and history are stored only on your computer, in the app's data folder. Passwords and keys are encrypted with a key protected by your operating system (Keychain on macOS). NavQL connects directly from your computer to the databases you configure. None of this is ever sent to us.

Anonymous usage statistics

To know how many people use NavQL, the desktop app sends a few anonymous events to Aptabase, a privacy-focused analytics service (servers in the United States):

  • install — once, after the app is installed;
  • active_day — at most once per day you use the app;
  • active_month — at most once per month you use the app.

Each event carries only the app version, the operating system and its version, the processor architecture (for example arm64) and the interface language.

Never sent: your name, e-mail or any account, connection names, hosts, database names, queries, table data, file names, or any identifier of you or your computer. NavQL does not create or store an ID for analytics, so events from the same computer cannot be linked together. Like any request on the internet, the connection to Aptabase carries your IP address; NavQL does not send it as data, and how Aptabase handles it is described in Aptabase's privacy policy.

Turning it off: click the chart button at the bottom of the Connections screen and uncheck Share anonymous usage statistics. On macOS, the same option is in the menu NavQL → Share Anonymous Usage Statistics. While it is off, nothing is sent.

Update checks

The app checks for new versions when it opens and every six hours, by reading the release information published on GitHub (github.com/wagnerdevel/navql-releases), and downloads new versions from there. These requests contain no personal data; GitHub handles them under the GitHub Privacy Statement.

AI assistant (optional)

The AI assistant only works if you add your own Anthropic API key, and only sends something when you use it. It then sends, directly from your computer to Anthropic, the structure of the database in use (table and column names, types and keys) and the text of the query editor — never table data. These requests are covered by your agreement with Anthropic and the Anthropic Privacy Policy.

This website

This site has no cookies, no ads and no analytics. It is hosted by GitHub Pages, which may log visits as described in GitHub's privacy statement. To show the latest version, the page reads public release data from the GitHub API, and it loads its fonts from Google Fonts. If you agree to the terms before downloading, your browser remembers that choice locally; it is never sent anywhere.

Changes

If what NavQL sends changes, this page will be updated before the version that changes it is released, and the date above will change.
